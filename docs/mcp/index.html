스킬·MCP 라이브러리 소개

"우리에게 필요한 AI 스킬은 무엇인가요?"

AI 도입 미팅 때마다 가장 많이 받는 질문입니다.

그 답을 한 곳에 모아두려고 이 사이트를 만들었습니다. AI에게 일하는 방법을 가르치는 스킬과, AI를 바깥 자료와 서비스에 연결하는 MCP 가운데 비즈니스 리더에게 진짜 필요한 것만 엄선했습니다.

01스킬

스킬은 AI에게 일하는 방법을 가르쳐 주는 설치형 지침 묶음입니다. 개발 전용 스킬은 최소화하고, 비즈니스·마케팅·리서치·투자 중심으로 직접 골랐습니다. 한국 특화 스킬도 별도 카테고리로 분리했습니다.

  • 비즈니스 리더가 바로 쓸 수 있을 것
  • 실무 검증이 끝났을 것
  • 한국 맥락에 맞을 것

02MCP

MCP는 AI를 바깥 자료와 서비스에 연결하는 표준 규격입니다. 국내 공시·법령부터 미국 SEC 공시까지, 따로 찾지 않으면 알기 어려운 한국·틈새 MCP를 중심으로 모았습니다.

  • 출처를 보자마자 알 수 있을 것
  • 개발자 전용이 아니라 비즈니스 리더가 쓸 것
  • 클로드가 이미 기본으로 연결한 유명 서비스는 제외

03사용법

  • 스킬 선택. 원하는 스킬의 GitHub 링크를 열어 SKILL.md와 함께 들어 있는 파일을 확인합니다.
  • 도구의 스킬 폴더에 복사. 사용하는 AI 도구(Claude Code, Codex, Antigravity 등)의 스킬 폴더에 파일을 넣으면 자동으로 인식됩니다. 도구별 경로는 각 공식 문서를 참고합니다.
  • 조합해서 쓰기. 스킬은 여러 개를 함께 써도 됩니다. 하네스로 팀을 짜고 워크플로우 스킬로 진행 방식을 잡으면 시너지가 커집니다.
  • MCP 연결. 카드를 눌러 저장소의 설치 안내를 따릅니다. 카드의 구분(바로 사용, 로그인만 필요, API 발급 필요)으로 준비물을 먼저 확인합니다.

04왜 만들었나요

조직에 AI를 도입할 때 저는 늘 "전용 스킬부터 만드세요"라고 조언드립니다. 표준 스킬이 먼저 깔려야 도입 속도가 달라지기 때문입니다. 이 사이트는 그 레퍼런스입니다.

05왜 'AI Roasting'인가요

좋은 원두를 고르고 로스팅해야 마실 만한 커피가 되듯, AI 스킬도 가려내고 다듬는 손이 필요합니다. 그 역할을 하겠다는 뜻입니다.
